# --instructions--

Every sudoku rule is about three kinds of group: rows, columns, and boxes. Each group is called a **house**, and each house holds the digits 1 to 9 exactly once.

![Three 9 by 9 grids side by side. The first shades the fifth row, the second shades the fifth column, and the third shades the center 3 by 3 box.](/images/learn/houses.svg)

Boxes are numbered 1 to 9, left to right and top to bottom. Box 1 is the top-left box, box 5 is the center, and box 7 is the bottom-left.

## Your task

Select all nine cells of box 7. Click a cell, or press <kbd>Space</kbd> on it, to add it to the selection or remove it. Selected cells show a check mark, and the blue outline shows where you are. The Next button appears once the selection is exactly box 7.

## How this lesson is built

This lesson shows how a `selected` requirement works. Its `# --config--` block has two parts.

The `board` object puts a classic sudoku in the right panel:

```json
{
  "board": {
    "variant": "classic",
    "givens": { "r1c3": 8, "r1c7": 5 },
    "solution": { "r1c1": 1, "r1c2": 7 },
    "cellSelection": "multiple",
    "highlights": { "peers": false, "sameValue": false }
  }
}
```

- `givens` and `solution` are trimmed here. The real block lists every cell of `solution`.
- `cellSelection: "multiple"` lets the learner select more than one cell. The default, `"single"`, allows one.
- `highlights` turns off peer and same-value shading, which would compete with the selection.

The `checklist` holds the lesson's requirements. The learner doesn't see the list, but the lesson is complete only when every requirement passes:

```json
{
  "checklist": [
    {
      "label": "Select box 7",
      "hint": "You should select the nine cells in the bottom-left box.",
      "test": { "selected": ["r7c1", "r7c2", "r7c3", "r8c1", "..."] }
    }
  ]
}
```

A `selected` test passes when the selection is exactly these cells, in any order. When a click moves the selection away from the target, the `hint` slides up from the bottom of the board panel. A click that adds a correct cell shows nothing.

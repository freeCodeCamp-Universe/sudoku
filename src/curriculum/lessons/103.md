# --instructions--

Skyscraper Sudoku follows the usual row, column, and box rules, and its edge clues show how many buildings are visible from each direction. A building is visible when it is taller than every building before it.

---

The board has two empty cells, r1c1 and r3c3. Each is the last empty cell in its row. Find the digit missing from each row and enter it.

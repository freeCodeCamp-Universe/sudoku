# --instructions--

A house holds the digits 1 to 4 exactly once. When a house has one empty cell left, the missing digit is the only one that can go there.

## Your task

The 4×4 board has two empty cells: r1c1, the first cell of row 1, and r3c3, the center cell. Each is the last empty cell in its row. Find the digit missing from each row and enter it.

Select a cell, then choose a digit on the number pad or type it. Make sure the **Normal** tab is active, because the **Candidate** tab adds pencil marks instead of values.

## How this lesson is built

This lesson uses the `mini` variant and shows how a `values` requirement works.

The `board` object gives every cell except the two targets:

```json
{
  "board": {
    "variant": "mini",
    "highlights": { "peers": false },
    // every cell except r1c1 and r3c3
    "givens": { "r1c2": 2, "r1c3": 3 },
    "solution": { "r1c1": 1, "r1c2": 2 }
  }
}
```

The board uses the default single-cell selection. Peer highlighting is turned off with `"highlights": { "peers": false }`; same-value and conflict highlights remain on by default.

The `checklist` holds one requirement per target cell:

```json
{
  "checklist": [
    {
      "label": "Fill r1c1",
      "hint": "You can find the digit that row 1 is missing.",
      "test": { "values": { "r1c1": 1 } }
    },
    {
      "label": "Fill r3c3",
      "hint": "You can find the digit that row 3 is missing.",
      "test": { "values": { "r3c3": 4 } }
    }
  ]
}
```

A `values` test passes when each listed cell holds that value. Requirements are checked from the top of the list. A wrong digit, or an entry in another cell, shows the hint of the first unfinished requirement. Once r1c1 is correct, a mistake shows the hint for r3c3 instead. Selecting a cell never shows a hint, because a `values` test only reacts to board entries.

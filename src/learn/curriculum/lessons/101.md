# --instructions--

Welcome to **Sudoku** and its interactive learning curriculum.

## What this curriculum gives you

- A two-panel lesson workspace (instructions + interactive area).
- A curriculum tree with module and lesson navigation.
- Progress tracking persisted across sessions.
- Keyboard shortcuts, theming (dark/light), and accessibility features.
- A build pipeline that pre-renders lessons to static JSON.

## How lessons are structured

Each lesson is a Markdown file in `src/learn/curriculum/lessons/`. Two layout types exist:

- **article** — a centered prose column (like this lesson). Good for introductions and reviews.
- **interactive** — a split panel with instructions on the left and your custom interactive area on the right.

Open the next lesson to see an interactive lesson in action.
